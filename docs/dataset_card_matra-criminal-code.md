# Dataset Card — matra-criminal-code (ประมวลกฎหมายอาญา)

> Draft for the Hugging Face dataset release. Everything here is generated by the open Matra pipeline; every number below is reproducible from `docs/run_e2e_criminal63.py`.

## Summary

The Thai Criminal Code (ประมวลกฎหมายอาญา), consolidated version `-63`, cleaned to the Matra v0.2 standard: 1,031 raw sections unglued into **34 documents** (enacting act, the code, and 32 subsequent instruments: 30 amendment acts + 1 announcement + 1 emergency decree), amendment-inserted structures **merged into their true positions** (terrorism ลักษณะ ๑/๑ · electronic-card หมวด ๔ · passport หมวด ๕ · corpse ลักษณะ ๑๓ — 31 payload rows, 7,237 chars, zero loss), full hierarchy tree + generated TOC (audit-matched: ภาค 3, ลักษณะ 16, หมวด 37, ส่วน 3), and a flat export of **485 มาตรา rows**.

## Flat columns (schema-frozen, `flat_profile.columns`)

`matra_cid · law_group_code · doc_id · doc_type · law_title_th · phak · laksana · muad · suan · matra_no · matra_no_arabic · status · effective_from · effective_until · text · refs_out · deka_refs · reference_url · is_latest_computed`

Semantics: breadcrumb columns (`phak/laksana/muad/suan`) carry ancestor headings so hierarchy survives flattening; `matra_no` is Thai-numeral verbatim, `matra_no_arabic` its Arabic mirror; `matra_cid = law_group_code:matra_no_arabic` is stable across consolidated versions (proven -00 ↔ -63); `refs_out` is regex-v0 cross-reference extraction with self-citations filtered; `is_latest_computed` is **group-derived** (see Known Defects — the source flag is broken).

## Known Defects

Berkson's rule: log the invisible, ship what's wrong alongside what works.

**Source-data defects (preserved verbatim, annotated):**
1. **Digit defect, sectionId 6466038** — the structural heading for ลักษณะ ทรัพย์ reads "ลักษณะ ๑" where the record's own table of contents (sectionId 6465658) correctly says "ลักษณะ ๑๒". Confirmed KRISDIKA source error; shipped as-is with a `known_defects` annotation. Downstream breadcrumbs for มาตรา ๓๓๔–๓๖๖ display the defective heading by design.
2. **Source `is_latest` flag broken** (multiple versions flagged true) — replaced by computed `is_latest_computed` (max timeline_seq per group). Note: the per-record tree envelope carries a legacy per-record value; consume the flat/wrapper values, which are group-derived.
3. **Source TOC corrupt in general** — regenerated at compile time (ironically, the source TOC is *correct* at defect #1, which is how the defect was proven).
4. **Tables were never digitized upstream** — sectionTypeIds 5/11/12 are vacant across 14,087 sections of the strongest candidate laws (tariff/revenue/excise); tables exist only as scanned-image references. Design intent on first sighting: e-LAWS-style attachment pointer nodes (wake trigger armed in the adoption ledger).
5. **publish_date equals the first-publication date on every consolidated version** of a group in the source — per-version gazette dates are not carried; deferred to the status engine.

**Pipeline v0 limitations (deliberate, tested boundaries):**
6. `status`/`effective_from`/`effective_until` = `"unknown"`/null — repealed/pending detection **deferred** until gazette-evidence-based status engine; never asserted without evidence.
7. `refs_out` recall unknown — regex v0 (มาตรา + optional ทวิ/ตรี/จัตวา suffix + optional แห่ง<law>); self-citations filtered by position; known edge: a leading-slash artifact form is not filtered; `deka_refs` empty (phase 2).
8. `application_scope` unpopulated in v0 (staged per-มาตรา commencement is real in Thai law; needs evidence source).
9. **Directive recognizer is recognize-only v0** with a greedy false-positive guard — merge decisions in this dataset come from positional algebra, not directive parsing.
10. **Headless fragments** (payload rows arriving with no heading row) are conserved-but-not-counted as structures — quarantine ledger carries them.
11. sectionTypeIds 17 (statutory-authority citations) and 19 (minister signature) are auto-quarantined pending promotion decision; 29 genuinely empty source records are flagged `empty_record`.
12. **`matra_cid` is unique per document, not per export file** — every amendment act carries its own boilerplate มาตรา ๑-๒, so e.g. `…:2` recurs across docs. Consumers key on (`doc_id`, `matra_cid`).
13. `eId` collisions caused by source defect #1 are disambiguated deterministically (`__d2` + `eid_collision` flag) rather than renumbered.
14. Thai script in identifiers: `matra_cid`/`law_group_code` keep Thai characters verbatim (they are identifiers, not URIs); an ASCII URI scheme is a v1 decision.
15. Machine translation: no `en` fields shipped in v0; `machine_translated` flag reserved by schema.
